# Triage labels

Use the GitHub label mapped to each role when applying a triage state.

| Triage role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue is waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue without additional context. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The issue will be closed without implementation. |
